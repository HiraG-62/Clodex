## 1. 部品のデザイン（PC）

- STYLE に `transition` が 1 つもない。`:hover` は 4 部品、`:active` は 1 部品だけ。押せるかどうかがカーソルでしか分からない
- ヘッダの `.ghost`（開く / 詳細 / 成果物 / 設定）はテキストの枠ボタン。hover の変化もない。トグルの `#detail` だけ押下中に白黒反転
- `#projects`（select）と `.path` に同じ project のパスが二重に出る。select はブラウザ標準の見た目で高さもずれる
- Agent の「中断 / Compact」が下線付きのテキストリンク。押せない「中断」にも赤みが残る
- `.send` は白一色で、送り先（Claude / Codex）とつながらない
- `.setting-chip` は押せることも、何の値かも分からない。`.role-button`（✎）は薄くて小さく、設定全体を開くのにペンの意味とずれる
- `.seg` の選択・`.primary-action`・`.ghost[aria-pressed]` が白黒反転で重く、送り先切り替えだけ質感が違う
- ゲージは 2px で、ラベルが折り返す。値がない Agent は「—」が 3 行並ぶ
- 会話一覧: 今の会話の背景が ⋯ まで届かない。作業中の印が Claude 色で固定
- シートの「閉じる」はテキスト。開閉のアニメーションがない
- 作業中タブは 0 件でも常に出る
- トーストに種類のアイコン・影・出入りの動きがない

### 良い部品: 送り先切り替え `.to`

1. くぼんだ下地（`--sunken`）の上に、選んだ項目が `--panel` で 1 段浮く（白黒反転しない）
2. 輪郭は `box-shadow: 0 0 0 1px var(--line)` で描く
3. 角丸が入れ子で揃う（外 6px − padding 2px = 内 4px）
4. 色は 6px の点だけ。面積で塗らない
5. 文字色は未選択 `--muted`、選択 `--fg`

これを全部品のデザイン言語にする（§4）。

## 4. 方針

- **デザイン言語**: `.to` の作り（くぼみ + 浮き + 1px の ring + 色は点だけ）を全部品に広げる。hover / press / selected / disabled / focus / loading の 6 状態をすべての操作部品に定義する。transition は 120ms 程度。`prefers-reduced-motion` で止める。白黒反転の主ボタンは 1 画面に 1 個まで
- **アイコン**: ヘッダと操作ボタンは inline SVG のアイコンのみにし、`aria-label` と `title`（tooltip）を必ず付ける。依存パッケージは増やさない（Lucide の path を `<symbol>` で埋め込む）。送り先や `.seg` の選択肢は文字のまま
- **ロード表示**: 共通の 3 部品を用意する。トップの不確定プログレスバー、ボタン内スピナー（`withPending`）、skeleton。state が変わるまでの待ちは `pendingPrimary` と同じ pending 状態にまとめる
- **スマホ**: PC の縮小ではなく専用レイアウトにする。方向性はモックのコンペで決める
