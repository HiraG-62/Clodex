# Web UI の細かい調整 2: 広い画面のレイアウト

DESIGN.md §17「レイアウト」の「画面が広いとき」を実装する。UI-POLISH-1（利用状況のポップオーバー）の後に行う。

## 今

- `.app` は `max-width: 1360px; margin: 0 auto`。広げると、会話の一覧も含めた全体が中央に寄り、両側が空く

## 変更

幅 1360px を超えたとき:

- 会話の一覧（左の列、300px）は画面の左端に固定する
- 右の列（Agent ストリップ・ログ・入力欄）の幅は今の最大幅（1360 − 300 = 1060px）のまま、**画面の中央**に置く
  - 画面の中央に置くと会話の一覧と重なる幅（1360〜1660px）では、一覧のすぐ右に置く（`left = max(300px, (100vw − 1060px) / 2)` 相当）
- 区切り線や背景は、左の列が画面の高さいっぱいに伸びて見えるようにする

幅 1700px 以上（右の余白が 320px 以上）のとき:

- 右端に**利用状況のパネル**（幅 300px、上下いっぱい）を常に出す。中身は UI-POLISH-1 のポップオーバーと同じ部品を、Claude と Codex の 2 つ並べる（見出しに mark と名前）
- このときミニゲージのポップオーバーは開かない（ミニゲージはボタンでなく表示だけにする。`aria-expanded` も外す）。開いていたポップオーバーは閉じる
- `state` が届いたら値だけ更新する

幅や数値は定数にする（`SIDE_WIDTH`、`CHAT_MAX_WIDTH`、`WIDE_USAGE_MIN_WIDTH` など。CSS とクライアントで同じ値を使う）。

## テスト

- Playwright（fixture。稼働中の Hub 4319 は使わない）で、幅 1280・1500・1920 の PC のスクショを撮る。1920 では右に利用状況のパネルが出て、ミニゲージを押してもポップオーバーが開かないこと、1500 では右の列が一覧と重ならないことを確かめる
- スマホ（390）が変わらないこと
- `pnpm test` と `pnpm typecheck` を通す
