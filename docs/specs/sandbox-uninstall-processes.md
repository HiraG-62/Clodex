# uninstall 時の残存プロセス停止と例外通知

削除対象プロファイルの SID を確定し、人・特殊プロファイルを除外した後、Win32_Process.GetOwnerSid が一致するプロセスだけ Terminate する。最大5秒、500ms間隔でプロファイルを再取得し、Loaded の解除を待つ。解除されなければエラーにする。

昇格前に sandbox-admin/error を人と Administrators のみに許可して空にする。昇格スクリプトの trap が例外メッセージだけを書き、非昇格側が失敗時に読み取って表示する。成功・失敗・UAC拒否のいずれも finally で除去し、前回の残存内容は次回に上書きする。資格情報やスクリプト全体は書かない。

プロセス・CIM・待機をスタブ化して検証する。実機の UAC / uninstall は実行しない。
